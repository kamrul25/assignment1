# TypeScript & Object-Oriented Programming Assignment (B8A1)

This repository contains my solutions for the **B8A1 Assignment: Problem Solving with TypeScript & OOP**.
The assignment covers core TypeScript fundamentals including optional parameters, union types, readonly tuples, generic functions, interfaces, OOP access modifiers, and asynchronous Promises.

## Repository Structure

* **`solutions.ts`**: Contains all 8 problem solutions implemented cleanly with explicit types, adherence to naming conventions, and proper handling of edge cases.
  
* **`type-aliases-vs-interfaces.md`**: Blog post covering the core differences between Type Aliases and Interfaces.
  
* **`access-modifiers-oop.md`**: Blog post explaining how Access Modifiers work in TypeScript Object-Oriented Programming.
